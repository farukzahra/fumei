# Fumei MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an Android app with one "Fumei" button that logs vape sessions locally and shows today's count + timestamps.

**Architecture:** Single-activity Compose app with MVVM. Room persists `PuffEntity` records. ViewModel exposes `TodayUiState` via StateFlow. Repository handles date-boundary queries.

**Tech Stack:** Kotlin, Jetpack Compose, Material 3, Room, ViewModel, StateFlow, JUnit 5

## Global Constraints

- Package name: `br.dev.faruk.fumei` (projeto `fumei.faruk.dev.br`)
- Min SDK 26, Target SDK 35
- No network permissions, no login, no cloud
- UI language: Portuguese (pt-BR)
- Time format: 24h (`HH:mm`)
- One tap = one `PuffEntity` with `timestamp = System.currentTimeMillis()`
- "Today" = device local timezone midnight boundaries

- [ ] **Step 3: Implement entity, DAO, database, repository**

```kotlin
// PuffEntity.kt
@Entity(tableName = "puffs")
data class PuffEntity(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val timestamp: Long
)

// PuffDao.kt
@Dao
interface PuffDao {
    @Insert suspend fun insert(puff: PuffEntity): Long
    @Query("SELECT * FROM puffs WHERE timestamp >= :start AND timestamp < :end ORDER BY timestamp DESC")
    suspend fun getPuffsBetween(start: Long, end: Long): List<PuffEntity>
    @Query("SELECT * FROM puffs WHERE timestamp >= :start AND timestamp < :end ORDER BY timestamp DESC")
    fun observePuffsBetween(start: Long, end: Long): Flow<List<PuffEntity>>
}

// PuffRepository.kt
class PuffRepository(private val dao: PuffDao) {
    suspend fun insertPuff() = dao.insert(PuffEntity(timestamp = System.currentTimeMillis()))

    fun observeTodayPuffs(): Flow<List<PuffEntity>> {
        val zone = ZoneId.systemDefault()
        val start = LocalDate.now().atStartOfDay(zone).toInstant().toEpochMilli()
        val end = LocalDate.now().plusDays(1).atStartOfDay(zone).toInstant().toEpochMilli()
        return dao.observePuffsBetween(start, end)
    }
}
```

```kotlin
class MainViewModel(private val repository: PuffRepository) : ViewModel() {
    private val _uiState = MutableStateFlow(TodayUiState())
    val uiState: StateFlow<TodayUiState> = _uiState.asStateFlow()

    init {
        viewModelScope.launch {
            repository.observeTodayPuffs().collect { puffs ->
                val formatter = DateTimeFormatter.ofPattern("HH:mm")
                _uiState.value = TodayUiState(
                    count = puffs.size,
                    times = puffs.map {
                        Instant.ofEpochMilli(it.timestamp)
                            .atZone(ZoneId.systemDefault())
                            .format(formatter)
                    }
                )
            }
        }
    }

    fun onFumeiClick() {
        viewModelScope.launch { repository.insertPuff() }
    }
}
```
